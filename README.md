# 🏋️ Gym Website Design

A modern and responsive gym landing page built using HTML5 and CSS3.  
This mini project showcases a professional fitness website UI with smooth animations, stylish navigation, and an attractive hero section.

---

## 🚀 Features

- 🧭 Responsive Navigation Bar
- 🎯 Hero Section with Call-to-Action
- 🏋️ Fitness Themed Landing Page
- ✨ Smooth Text & Image Animations
- 🔥 Hover Effects for Navigation Links
- 🎨 Background Overlay Design
- 📱 Responsive Layout Structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations
- Flexbox

---

## 🎨 Sections Overview

### 🏠 Home (Hero Section)

- Attractive fitness headline
- Membership call-to-action button
- Animated content and gym model image

### 🧭 Navigation Bar

**Includes:**

- Home
- About
- Gyms
- Membership
- Reviews
- Login Button

### ✨ Animations

- Smooth fade-up animation
- Hover underline effects
- Button shadow hover effects

---

## 💡 How to Run

Clone the repository:

```
git clone https://github.com/Sivaponnuvel/Gym-Website
```

Open the project folder

Run `index.html` in your browser
